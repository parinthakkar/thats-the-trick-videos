# Dadi Ke Kisse inbox

Drop box for the Hindi channel "Dadi Ke Kisse". The daily Claude task puts new Shorts here
(<slug>.mp4, <slug>.png, <slug>.json); the workflow in parinthakkar/dadi-ke-kisse-videos copies them
every hour and uploads them to YouTube. This branch is separate from main and is not used by the
That's The Trick automation. Files older than 7 days are removed by the daily task.
